# Ad-Genie (FYP)

Ad-Genie is an AI-powered advertisement generation platform developed as a **Final Year Project (FYP)**.

## Project Structure

frontend/ → Frontend (React / Vite)
backend/ → Backend (Node.js / Express / API)

## Tech Stack

**Frontend:** React / Vite / Tailwind
**Backend:** Node.js / Express
**AI:** Deep Learning and GenAI
**Database:** MongoDB

## How to Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### **Backend**

```
cd backend
npm install
npm run dev
```
